## 🎮 Sobre o projeto

**AmethystLib** é uma biblioteca desenvolvida em **Java** com o objetivo de fornecer uma base para criação de **jogos 2D**.

O projeto foi desenvolvido do zero como um estudo prático de desenvolvimento de bibliotecas, programação orientada a objetos, processamento gráfico e construção de uma estrutura reutilizável para jogos.

A ideia da biblioteca é abstrair parte da complexidade envolvida na criação de um jogo, fornecendo uma estrutura que pode ser utilizada por outros projetos Java.

---

## ✨ Características

A AmethystLib foi criada pensando em uma estrutura reutilizável para projetos de jogos 2D.

Entre os conceitos trabalhados no projeto estão:

- 🎮 Desenvolvimento de jogos 2D
- ☕ Desenvolvimento em Java
- 🧩 Criação de uma biblioteca reutilizável
- 🖼️ Renderização gráfica
- ⌨️ Entrada de teclado
- 🖱️ Interação com o usuário
- 🔄 Game loop
- 📦 Organização de componentes reutilizáveis
- 🏗️ Programação orientada a objetos

# 🧠 Conceitos envolvidos

O desenvolvimento da AmethystLib envolveu diversos conceitos importantes de programação:

### ☕ Java

Utilização da linguagem Java para construção da biblioteca e de sua arquitetura.

### 🎮 Game Development

Implementação de conceitos necessários para construção de aplicações interativas e jogos 2D.

### 🔄 Game Loop

Estrutura responsável por manter o ciclo de execução da aplicação, processando continuamente a lógica e a atualização do jogo.

### 🖼️ Renderização

Processamento e exibição dos elementos gráficos utilizados pelo jogo.

### ⌨️ Input

Tratamento das interações do usuário através dos dispositivos de entrada.

### 🧩 Biblioteca reutilizável

Em vez de desenvolver toda a estrutura do jogo novamente em cada projeto, a AmethystLib fornece uma base reutilizável para novas aplicações.
